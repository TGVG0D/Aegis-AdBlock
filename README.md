# 🛡️ Aegis AdBlock

**Bloqueador de anúncios, rastreadores e elementos indesejados para Mozilla Firefox.**

O Aegis AdBlock é uma extensão de navegador desenvolvida para oferecer proteção durante a navegação, permitindo bloquear anúncios, rastreadores, domínios maliciosos e elementos visuais indesejados.

Com um painel de gerenciamento próprio, o usuário pode administrar listas de filtros, criar regras personalizadas, consultar estatísticas e controlar quais sites podem ou não carregar determinados recursos.

O projeto prioriza o processamento local e a privacidade: as configurações e os dados de navegação são armazenados no próprio dispositivo.

---

## 📥 Instalação

<badge color="success">Disponível no Mozilla Add-ons</badge>

### Instalação pelo Firefox

A maneira recomendada de instalar o Aegis AdBlock é diretamente pela loja oficial de extensões do Firefox.

**[🦊 Instalar Aegis AdBlock — Mozilla Add-ons](https://addons.mozilla.org/pt-BR/firefox/addon/aegis-adblock/)**

1. Acesse a página oficial da extensão.
2. Clique em **Adicionar ao Firefox**.
3. Confirme a instalação.
4. Acesse o ícone do Aegis AdBlock na barra de ferramentas.

### Instalação para testes

1. Extraia os arquivos do projeto.
2. Abra o Firefox.
3. Acesse `about:debugging`.
4. Entre em **Este Firefox**.
5. Clique em **Carregar extensão temporária**.
6. Selecione o arquivo `manifest.json`.

A extensão será carregada para testes. Extensões temporárias podem precisar ser carregadas novamente após reiniciar o navegador.

## 🔒 Privacidade

- Configurações armazenadas localmente.
- Histórico de bloqueios armazenado no dispositivo.
- Estatísticas processadas localmente.
- Nenhuma conta necessária.
- Não exige cadastro ou autenticação externa.
- Não depende de servidor próprio para o funcionamento principal.

Listas externas precisam acessar seus respectivos servidores para baixar atualizações.

## 📚 Listas de filtros

O Aegis AdBlock oferece suporte a fontes externas e listas recomendadas, incluindo:

- EasyList
- EasyPrivacy
- EasyList Portuguese
- Fanboy's Annoyance
- AdGuard Base Filter
- AdGuard Tracking Protection
- StevenBlack Hosts
- HaGeZi Pro
- HaGeZi TIF
- URLhaus
- uBlock Origin Privacy

As listas são opcionais e podem ser administradas pelo painel.

---

## ⚠️ Limitações

- Nem todas as opções da sintaxe EasyList são suportadas.
- Algumas regras podem ser identificadas como inválidas ou incompatíveis.
- Filtros cosméticos dependem dos seletores disponíveis.
- Algumas páginas podem apresentar problemas com filtros agressivos.
- A eficácia depende das listas instaladas e de suas atualizações.
